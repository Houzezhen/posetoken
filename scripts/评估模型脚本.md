# validate_piper.py 使用说明

通过回放 LeRobot 数据集中的观测，对已训练的 `pi05_piper` 策略做离线精度评估。
支持两种旋转表示：**四元数（7 维）** 和 **rotation6d（9 维）**。

## 两个版本对照

| 项 | 四元数版（7 维） | rotation6d 版（9 维） |
|----|------------------|-----------------------|
| 脚本路径 | `/home/user/openpi05/scripts/validate_piper.py` | `/home/user/openpi05_tcp/scripts/validate_piper.py` |
| 工作目录 | `/home/user/openpi05` | `/home/user/openpi05_tcp` |
| 输出维度 | 7 = `[x,y,z, qw,qx,qy,qz]` | 9 = `[x,y,z, r00,r10,r20,r01,r11,r21]` |
| 数据集（去掉 gripper） | 8 维 → 取前 7 维 | 10 维 → 取前 9 维 |
| LeRobot 数据集 | `TCP/data_toiletButton_0626_quaternion` | `TCP/data_toiletButton_0626_rotation6d` |
| Checkpoint | `data_toiletButton_0626_quaternion/15000` | `data_toiletButton_0626_6D/15000` |

---

## 四元数版（7 维）

### 1. 启动策略服务器（终端 A）

```bash
cd /home/user/openpi05
CUDA_VISIBLE_DEVICES=1 uv run scripts/serve_policy.py policy:checkpoint \
    --policy.config=pi05_piper \
    --policy.dir=checkpoints/pi05_piper/data_toiletButton_0626_quaternion/15000 \
    --port=8123
```

等待日志出现 server ready。

### 2. 运行验证（终端 B）

```bash
cd /home/user/openpi05
CUDA_VISIBLE_DEVICES="" uv run scripts/validate_piper.py \
    --host=localhost --port=8123 \
    --repo-id=TCP/data_toiletButton_0626_quaternion \
    --episodes=0,1,2,3,4 \
    --sample-steps=20 \
    --out-png=validation_result.png
```

## 常用参数

| 参数 | 默认值（四元数/6D） | 说明 |
|------|---------------------|------|
| `--host` / `--port` | `localhost` / `8123` | 策略服务器地址 |
| `--repo-id` | 对应版本数据集 | LeRobot 数据集（短格式会自动加 `~/.cache/huggingface/lerobot/` 前缀，也支持完整绝对路径） |
| `--episodes` | `0,1,2` | 要验证的 episode 列表，逗号分隔 |
| `--sample-steps` | `10` | 每个 episode 均匀采样的时刻数 |
| `--horizon` | `50` / `10` | 评估的预测步长（模型总输出 50 步，可截取前 N 步） |
| `--prompt` | `press the toilet button` | 语言指令 |
| `--out-png` | `validation_result.png` | 误差曲线图输出路径 |
| `--out-npz` | `None` | 可选，保存原始 pred/gt 数组 |

## 输出

- **终端**：Overall MSE、每个维度的 MSE/MAE、有效预测步长
- **PNG**：3 个子图（per-step 误差曲线 / per-dim MSE 柱状图 / per-dim MAE-vs-step 折线）
